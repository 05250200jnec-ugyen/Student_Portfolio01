# Ugyen Dorji | Portfolio

A responsive, multi-page personal portfolio website built from scratch with HTML, CSS and JavaScript.
It introduces my background as a Computer System and Network student at Jigme Namgyel
Engineering College (JNCE), Bhutan, and shows my skills, projects, education and contact details.

**Live site:** [ADD YOUR VERCEL LINK]

## Features

- Dark and light theme toggle that remembers your choice
- Mobile navigation menu and responsive layout
- Typing effect and animated terminal in the hero section
- Skill tabs with animated progress bars
- Project filter (All, Networking, Coding)
- Scroll animations and highlighted navigation link for the current page
- Contact form with validation that opens the visitor's email app
- Back-to-top button

## Pages

1. Home
2. About Me
3. Skills
4. Projects
5. Education & Certifications
6. Contact Me

## Built with

- HTML5
- CSS3
- JavaScript (no frameworks)
- Google Fonts (Sora and JetBrains Mono)
- Vercel for hosting

## Run it locally

1. Download or clone this repository.
2. Keep all the files in the same folder.
3. Open `index.html` in a web browser.

No installation is needed.

## Deployment

1. Push the project to a GitHub repository.
2. Sign in to [Vercel](https://vercel.com) and import the repository.
3. Deploy with the default settings, as no build step is needed.
